# Activity 8 — Temperature Experiment

## 1. Objective

The objective of this activity is to understand how temperature affects the responses generated by a Large Language Model (LLM). The same prompt is tested at temperatures 0.1, 0.7, and 1.0 to compare predictability and creativity.

## 2. Procedure

1. Select an LLM through an API or inference provider that supports temperature settings.
2. Use the same prompt for all three experiments.
3. Set the temperature to 0.1 and generate a response.
4. Repeat with temperatures 0.7 and 1.0.
5. Compare the outputs based on consistency, predictability, and creativity.

**Example prompt:** "Write a short paragraph about the future of artificial intelligence."

Example Python code using the Groq API:

```python
from groq import Groq

client = Groq()

prompt = "Write a short paragraph about the future of artificial intelligence."

for temperature in [0.1, 0.7, 1.0]:
    response = client.chat.completions.create(
        model="llama-3.3-70b-versatile",
        messages=[{"role": "user", "content": prompt}],
        temperature=temperature,
        max_tokens=150
    )

    print(f"\nTemperature: {temperature}")
    print(response.choices[0].message.content)
```

## 3. Observations

### A. Which output felt most predictable? Which was most creative?

**Temperature 0.1:** The output was generally more predictable and consistent. The model tended to select higher-probability next tokens.

**Temperature 0.7:** The output showed a balance between predictability and variation. It could provide different expressions and ideas while remaining relevant to the prompt.

**Temperature 1.0:** The output generally allowed more variation and could feel more creative or surprising. However, it could also become less consistent or less focused.

The exact results depend on the model and the prompt.

### B. Does temperature change what the model knows?

No. Temperature does not directly change the model's learned knowledge or parameters. Instead, it changes how the model selects the next token from its probability distribution.

A lower temperature generally favors more probable tokens, while a higher temperature allows less probable tokens to be selected more often. Therefore, the response may differ even though the underlying model remains the same.

### C. When would you want low temperature?

Low temperature is useful when consistency and predictability are important, such as:

1. Answering factual questions.
2. Summarizing documents.
3. Extracting information from text.
4. Generating structured responses.
5. Assisting with technical tasks where consistency matters.

However, low temperature does not guarantee factual correctness.

### D. When would you want high temperature?

Higher temperature is useful when variety and creativity are desirable, such as:

1. Creative writing and storytelling.
2. Brainstorming new ideas.
3. Generating different titles or slogans.
4. Exploring alternative explanations.
5. Producing varied conversational responses.

Higher temperature can also increase the chance of irrelevant or inaccurate output.

## 4. Conclusion

Temperature controls the randomness of token selection during text generation. A temperature of 0.1 generally produces more predictable responses, 0.7 provides a balance between consistency and variety, and 1.0 generally allows greater variation.

Temperature does not directly change what the model has learned. It changes how the model generates its response. The appropriate setting depends on whether the task requires consistency or creativity.

## 5. Result

The temperature experiment demonstrates that changing the temperature can affect the style, variation, and predictability of an LLM's output, even when the model and prompt remain the same.
